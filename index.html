What is
SCTF?

SCTF is a Jeopardy-style Capture The Flag platform: challenges are grouped into fixed categories, each worth a set number of points, and solved independently in any order you like. Break a challenge, find the hidden flag, submit it, and watch your score climb.

Platform Features

Authentication

Sign up with email or Google OAuth, login securely, and manage your account with password reset and profile updates.

Challenge System

Browse, search, and filter challenges by category or level. View detailed challenge information and submit flags for points.

Flag Submission

Submit flags for instant validation. Correct answers add points and mark challenges as solved. Invalid flags trigger error messages.

User Management

View user profiles, list all users, and search for specific users. Track solved challenges and challenge creation history.

Leaderboard & Scoring

Live ranking system showing top scorers. Points update in real-time when flags are submitted correctly.

My Challenges

Create, edit, and manage your own challenges. Track submission status: On Submission, Published, Revision, or Rejected.

Bookmark & Report

Save favorite challenges with bookmarks. Report issues on challenges for admin review.
