Users & Profiles

Temukan sesama pemain, jelajahi profil, kelola akun Anda, dan pahami apa yang terjadi jika akun ditangguhkan.

// daftar pengguna

All Users

Halaman Users menampilkan seluruh anggota komunitas SCTF. Anda dapat mencari, menyortir, dan melihat profil setiap pengguna untuk mengetahui pencapaian mereka.

  • Pencarian Cerdas (Fuzzy): Temukan pengguna meskipun ada kesalahan ketik. Algoritma Levenshtein Distance membantu mencocokkan nama dengan tingkat kemiripan.
  • Pencarian Eksak: Cari berdasarkan nama atau username secara presisi.
  • Urutkan: Atur daftar berdasarkan poin, jumlah tantangan yang diselesaikan, nama, atau tanggal bergabung.
  • Paginasi: 64 pengguna per halaman untuk kenyamanan browsing.

Klik pada kartu pengguna untuk melihat profil lengkap mereka, termasuk tantangan yang telah diselesaikan dan statistik lainnya.

// fitur

  • Pencarian Fuzzy + Exact
  • Sortir Poin, Solved, Nama, Waktu
  • Paginasi 64 / halaman
  • Detail Profil Overview + Challenges
// mode

Fuzzy Search

Gunakan Smart Fuzzy Search untuk menemukan pengguna meskipun ejaan tidak sempurna. Sistem menghitung kemiripan string dan menampilkan hasil terbaik.

// mode

Exact Search

Pencarian presisi untuk hasil yang akurat. Cocok digunakan jika Anda sudah tahu persis nama atau username pengguna.

⏱️

Auto‑search Timer

Setelah Anda berhenti mengetik selama 5 detik, pencarian akan dijalankan secara otomatis. Sebuah indikator menunjukkan waktu tersisa, dan Anda dapat membatalkan atau memicu pencarian secara manual kapan saja.

// pengaturan akun

Edit Profile

Halaman /profile/edit memungkinkan Anda memperbarui informasi pribadi, mengunggah foto profil, dan mengelola akun.

Yang Dapat Diubah

  • Nama Tampilan – nama yang terlihat oleh pengguna lain
  • Username – identitas unik Anda
  • Email (hanya untuk pengguna dengan autentikasi email)
  • Bio – cerita singkat tentang diri Anda
  • Negara – dari mana Anda berasal
  • URL GitHub – tautan ke profil GitHub Anda
  • Foto Profil – upload gambar (JPEG, PNG, GIF, WebP, maks 5MB)

Catatan Penting

  • → Pengguna Google: Email tidak dapat diubah karena dikelola oleh Google.
  • → Perubahan foto profil langsung diterapkan setelah upload.
  • → Data lain harus disimpan dengan mengklik tombol Save Changes.
  • → Ganti password tersedia di /profile/password (khusus pengguna email).
🔑

Ganti Password

Pengguna dengan autentikasi email dapat mengganti password melalui halaman /profile/password. Masukkan password lama dan password baru (minimal 8 karakter) beserta konfirmasinya. Jika password lama benar dan konfirmasi cocok, password akan diperbarui.

⚠️ Pengguna Google: Password dikelola oleh Google. Untuk mengganti password, silakan ubah melalui akun Google Anda.

// penangguhan

Suspended Users

Akun yang melanggar aturan platform dapat dikenai suspensi (penangguhan) sementara atau permanen. Halaman ini menjelaskan bagaimana suspensi bekerja dan apa yang dapat dilakukan pengguna.

Jenis Suspensi

  • ⏳
    Temporary

    Akun dinonaktifkan untuk jangka waktu tertentu. Pengguna dapat melihat sisa waktu dan akan otomatis pulih setelah masa suspensi berakhir.

  • 🚫
    Permanent

    Akun dinonaktifkan secara permanen. Tidak ada pemulihan otomatis; pengguna harus menghubungi dukungan jika merasa ada kesalahan.

Halaman Suspensi

Pengguna yang sedang dalam masa suspensi akan diarahkan ke halaman /suspended ketika mencoba mengakses platform. Halaman ini menampilkan:

  • Jenis suspensi (temporary/permanent)
  • Alasan suspensi
  • Waktu mulai dan (jika temporary) waktu berakhir
  • Jumlah hari tersisa (untuk temporary)
  • Tombol Logout dan Contact Support

💡 Tips: Jika suspensi sudah berakhir, refresh halaman untuk memperbarui status. Jika masih terkendala, hubungi tim dukungan.

🔒

Akses Diblokir

Selama masa suspensi, pengguna tidak dapat mengakses fitur apa pun di platform, termasuk melihat challenge, mengirim flag, atau mengedit profil. Semua upaya akses akan diarahkan ke halaman suspensi. Setelah suspensi berakhir (untuk temporary), akses akan pulih secara otomatis.
