// my challenge Creator Hub

My Challenge

Buat, kelola, dan kirim challenge CTF Anda sendiri. Pelajari aturan, ikuti praktik terbaik, dan berkontribusi untuk komunitas SCTF.

// overview

Ruang Kerja Challenge Anda

My Challenge adalah ruang kerja pribadi Anda untuk membuat dan mengelola challenge CTF. Dari sini, Anda dapat:

  • Membuat challenge baru dengan penyimpanan flag terenkripsi
  • Mengedit dan memperbarui challenge yang sudah ada
  • Mengirim challenge untuk ditinjau admin
  • Melacak status pengiriman Anda
  • Melihat umpan balik revisi dan melakukan perbaikan

Semua challenge melalui proses review sebelum dipublikasikan. Hal ini memastikan kualitas, kebenaran, dan nilai edukasi bagi semua peserta.

// statistik challenge

  • Status Saved · Submitted · Review · Published
  • Waktu Review 3–7 hari
  • Enkripsi Flag Vigenere + Base64
  • Write-up Google Docs

// panduan

Buat Sebuah Challenge

01

Isi Informasi Dasar

Berikan Challenge Name dan Description yang menjelaskan konteks dan tujuan.

02

Tambahkan Konten Challenge

Sertakan Task Strings (instruksi/petunjuk) dan opsional Task URL untuk sumber daya eksternal.

03

Atur Flag

Masukkan flag dalam format SCTF{...}. Flag akan dienkripsi otomatis menggunakan Vigenere cipher + Base64.

04

Sediakan Write-up

Tempelkan tautan Google Docs write-up Anda. Pastikan dapat diakses oleh siapa pun yang memiliki tautan.

🔐

Enkripsi Flag

Flag Anda dienkripsi otomatis melalui dua langkah: Vigenere Cipher → Base64. Kunci acak dibuat per challenge dan disimpan aman di tabel terpisah. Ini menjamin flag tetap terlindungi bahkan jika basis data dibobol.

// pengiriman

Kirim Challenge Anda

Setelah challenge siap, kirim untuk ditinjau admin. Proses review memastikan kualitas, kebenaran, dan nilai edukasi sebelum challenge dipublikasikan.

Cara Mengirim

  1. Pergi ke My Challenges dari sidebar.
  2. Temukan challenge tersimpan Anda di daftar.
  3. Klik tombol Submit.
  4. Konfirmasi pengiriman — status berubah menjadi On Submission.
  5. Tunggu review admin (biasanya 3–7 hari).

Status Pengiriman

  • ●
    Saved

    Draf — masih bisa diedit, belum dikirim.

  • ●
    On Submission

    Menunggu review admin.

  • ●
    Under Review

    Admin sedang aktif meninjau challenge Anda.

  • ●
    Revision

    Perubahan diminta — periksa umpan balik dan kirim ulang.

  • ●
    Published

    Challenge sudah tayang! Semua pengguna bisa menyelesaikannya.

  • ●
    Rejected

    Challenge tidak diterima — lihat umpan balik untuk alasan.

Praktik Terbaik

Informasi Lengkap

  • Nama challenge yang jelas dan deskriptif
  • Deskripsi detail dengan konteks
  • Tingkat kesulitan yang sesuai (ditentukan oleh admin)
  • Spesifikasi format flag yang benar

Persyaratan Teknis

  • Dapat diselesaikan dengan sumber daya yang disediakan
  • Tidak ada dependensi tersembunyi
  • Izin file & aksesibilitas yang tepat
  • Tautan unduhan berfungsi (jika ada)

Dokumentasi (Write-up)

  • Write-up lengkap di Google Docs (dapat diakses siapa pun dengan tautan)
  • Panduan solusi langkah demi langkah dengan penjelasan
  • Penjelasan kerentanan dan konsep
  • Nilai edukasi dijelaskan dengan jelas

Jenis Challenge

🔍 Forensics

  • Analisis format file · Memory dumps · Network captures
  • Analisis log file · Steganography

🌐 Web Exploitation

  • SQL Injection · XSS · CSRF · File Upload · Auth Bypass

💻 Binary Exploitation

  • Buffer overflows · Format string · ROP chains
  • Shellcode · Reverse engineering

🔐 Cryptography

  • Classic ciphers · RSA · Hash collisions
  • XOR encryption · Modern crypto weaknesses

⭐ Praktik Terbaik

🎯 Desain Challenge

  • Mulai dengan tujuan pembelajaran yang jelas
  • Uji challenge Anda secara menyeluruh
  • Berikan petunjuk yang sesuai
  • Pertimbangkan berbagai tingkat keahlian
  • Buatlah menyenangkan dan menarik

📝 Dokumentasi

  • Tulis deskripsi yang jelas dan ringkas
  • Gunakan tata bahasa dan ejaan yang benar
  • Sertakan contoh yang relevan
  • Berikan konteks dan latar belakang
  • Gunakan format yang konsisten
💡

Tips Pro

  • Buat challenge yang Anda sendiri nikmati untuk menyelesaikannya
  • Dapatkan umpan balik dari rekan sebelum mengirim
  • Riset challenge serupa untuk menghindari duplikasi
  • Utamakan nilai edukasi
  • Seimbangkan kesulitan dengan aksesibilitas
